# Implementation Plan: Logbook & Telemetry

**Branch**: `003-logbook-telemetry` | **Date**: 2026-05-03 | **Spec**: [spec.md](spec.md)

## Summary

Implement the `fill_ups` and `trips` tables with their full CRUD/logic stack: two new migrations, two Eloquent models, two repository pairs, two policies, two form requests, two controllers, two API resources, and a `TripObserver` that auto-increments the car odometer on trip creation. The fill-up index returns live consumption statistics via a dedicated repository method. The user's car and user repositories are also extended with the missing `allowedDefaultSorts`, `allowedIncludes`, and `allowedFiltersExact` declarations required by the constitution.

**Constitution violation corrected**: The input spec referenced `api/v1/` URL prefix and `Api\V1\` controller namespace — both forbidden by the constitution. Routes are at `/api/cars/{car}/fill-ups` and `/api/cars/{car}/trips`; controllers live at `app/Http/Controllers/`.

### Migrations

**`create_fill_ups_table`**

Schema::create('fill_ups', function (Blueprint $table) {
    $table->id();
    $table->foreignId('car_id')->constrained('cars')->cascadeOnDelete();
    $table->decimal('liters', 8, 2);
    $table->integer('odometer');
    $table->decimal('cost_egp', 10, 2);
    $table->date('fill_date');
    $table->timestamps();
});

**`create_trips_table`**
```php
Schema::create('trips', function (Blueprint $table) {
    $table->id();
    $table->foreignId('car_id')->constrained('cars')->cascadeOnDelete();
    $table->dateTime('start_time');
    $table->dateTime('end_time');
    $table->decimal('start_lat', 10, 8);
    $table->decimal('start_lng', 11, 8);
    $table->decimal('end_lat', 10, 8);
    $table->decimal('end_lng', 11, 8);
    $table->decimal('total_distance_km', 8, 2);
    $table->timestamps();
});
```

### FillUpRepositoryEloquent — statistics()
```php
public function statistics(int $carId): array
{
    $row = app($this->model())->newQuery()
        ->where('car_id', $carId)
        ->selectRaw('
            COUNT(*) as total_fill_ups,
            COALESCE(SUM(cost_egp), 0) as total_cost_egp,
            COALESCE(SUM(liters), 0) as total_liters,
            COALESCE(MAX(odometer), 0) as max_odometer,
            COALESCE(MIN(odometer), 0) as min_odometer
        ')
        ->first();

    $avg = $row->total_liters > 0
        ? round(($row->max_odometer - $row->min_odometer) / $row->total_liters, 2)
        : 0;

    return [
        'total_fill_ups'       => (int) $row->total_fill_ups,
        'total_cost_egp'       => number_format((float) $row->total_cost_egp, 2, '.', ''),
        'average_consumption'  => number_format($avg, 2, '.', ''),
    ];
}
```

### TripController — Haversine private method
```php
private function haversineKm(float $lat1, float $lng1, float $lat2, float $lng2): float
{
    $r    = 6371;
    $dLat = deg2rad($lat2 - $lat1);
    $dLng = deg2rad($lng2 - $lng1);
    $a    = sin($dLat / 2) ** 2
          + cos(deg2rad($lat1)) * cos(deg2rad($lat2)) * sin($dLng / 2) ** 2;
    return $r * 2 * atan2(sqrt($a), sqrt(1 - $a));
}
```
